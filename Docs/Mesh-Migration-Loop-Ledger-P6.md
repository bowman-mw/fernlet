## Surprises worth not re-deriving
- A `until ! pgrep -f "xcodebuild …"` poll loop matches its OWN command string and never ends — use `pgrep -x xcodebuild` or the log's terminal marker.
- **Every pass runs the FULL suite before its commit.** Two passes that skipped it (item 1 pass A, item 2 pass A) each left a red the next pass had to find and fix — a subset gauntlet is not a commit gate. `full-1.log`-style: a ~350 s runner hang with ZERO tests can follow even a warm subset — re-launch; `error:` is useless as a needle on a full log (CoreData teardown lines), `recorded an issue` is the needle.
- **zsh passes an unquoted `$ARGS` string as ONE argument**: 69 `-only-testing:` flags became one flag → `Executed 0 tests` under `TEST EXECUTE SUCCEEDED` + `EXIT=0` (item 3). Build the flags into an array (`ARGS+=(…)`, `"${ARGS[@]}"`). Only the missing `Test run with N tests` line caught it.
