## Surprises worth not re-deriving
- **The assert family was 40 traps, not 19.** The plan's 19 counted the literal `catch` shape; eight siblings were `guard let x = try? … else { assertionFailure }` on the same environmental failures (a store fetch, a payload encode of a non-finite `Double`). Enumerate by failure class, not by syntax.
- **Removing an `assertionFailure` can remove the only signal for a silent data revert.** `SavedRecipe.apply`'s encode `catch` left the previous `payloadData` on the record; the read path prefers the blob whenever the legacy projection has not diverged, so an edit to a structured-only field vanished on the next load. Every converted `catch` must leave the row in the state the *read path* expects, not merely "not trap".
- **A controller whose store never loaded is NOT a throwing rig**: zero stores → empty fetch, no-op save, nothing throws (and an insert crashed the runner). To make saves throw, re-attach the SAME store with `NSReadOnlyPersistentStoreOption`; to make fetches throw, overwrite the database file (and WAL) under the open connection — SQLite re-reads page 1 per read transaction.
- **A test that builds `LocalFernletRepository` without `legacyDefaults:` purges `UserDefaults.standard`** when it drives `purgeAllPersistedData()` — the seam's own doc comment names the hazard; pass `isolatedDefaults()` and `backupExclusionPreference: { false }` on every construction.
- **`power-of-10-scan.py`'s assertion-density floor counts `assertionFailure` as a check**: 27 removals moved 0.775 → 0.770 against a 0.68 floor. A future sweep of this shape moves it further.
- **A continued-processing task is delivered while the app is still in the foreground.** Any state meaning "we are continuing in the background" keys on (task in hand ∧ scene dark).
- **Gating cost is not proportional to cell count**: +92 % cells cost +10 % wall time on a tier-1 step. Price a gate before deferring it.
- **A hold is not a stop**: every clock that assumes browsing must pause with the radios — grep every `arm…Clock` when adding a pause-shaped verb.
- **A terminal state erases its cause unless a projection rule keeps it**; and **a reset that clears state without walking the table strands every side effect the table owed**.
- **`hasSlot(for:)` means ANY slot** — read the body of every predicate a new door consults; a **re-entry row keys on facts, not on `previous`**.
- **A protocol requirement declared in an app file is a second occurrence of a grep-wall's needle**; **a grep for `@Suite` under-counts the suites** (some are plain structs found by their `@Test`s).
- **A background build's notified exit code is the last command's**; **a Simulator that has run ~3 h stops rendering** — erase and reboot before believing a UI red.
- **Every P8 adversarial verify found something real.** Seven for seven; five would have shipped. **P9 item 1's did too** (the stale blob).
- **Every P6 and P7 lesson still binds**: a log with `Restarting after unexpected exit` has no usable total; never chain a build and a run on one DerivedData; `-only-testing:` names the SUITE; `@Test(arguments: [])` is green over nothing; a process-global audit signal cannot witness a per-cell claim; `.inactive` is foreground for the radios; `FernletLockState` carries associated values; the chat age gate is `AgeGate.chat`; zsh passes an unquoted `$ARGS` as one argument.
- **Closed; do not re-audit:** `MeshTunnelConvergence`, the id-vs-endpoint family, the crypto-purpose / `PayloadType` / record-kind spellings, plan §10.7–§10.10, §11.1–§11.4, §12.1–§12.4, §13.1–§13.4 and §14.1–§14.4; `Docs/Proximity-Security-Followups-2026-08-18.md` §1. Concurrent sessions share the tree; never stage the catalog working copy, `xcuserdata`, or the stray PDF.
- **A worktree has its own DerivedData** (the path hash differs from the primary's): the first build there is cold (~20 min here), and "one `xcodebuild` at a time" is a CPU rule as much as a DerivedData rule — `pgrep -x xcodebuild` still gates every start.

- **Rebuild the app before a lane run, always**: the "warm" app binary was stamped one minute BEFORE the last code commit, so it could not have contained it — a build log's date is not the tree's date.
- **Kill audit streams by saved PID, never `pkill -f "log stream"`**: the pattern matched a concurrent session's `backboardd` orientation stream on a Simulator (spawned through Claude.app's helper) and killed it.
- **Four Simulators are as cheap as two**: boot-to-usable ~25 s on the fourth, and the four-node full mesh converged in ~3 s — the same as the pair. At N ≥ 4 two `tunnel activated, tunnels=2` lines can land in one instant (three distinct sids, final `tunnels=3`) — a log-ordering artefact, not a duplicate.
- **A seeded harness run converges the descriptor roster only** (`membership ledger=absent derived=0`) — correct per the 2026-09-12 correction; do not read it as a derived-roster proof.

- **A rotation test can only see fields that CHANGE.** The certificate's validity window is the one part of the posture that is supposed to be identical across devices, so the raw-`now` leak survived the whole rotation table; the cell that catches it asserts two mints at different instants in one epoch are byte-identical. When a value must be unlinkable, pin the fields that must match as hard as the ones that must differ.
- **The MC presence radio wears one name for its whole life while its tags rotate** (`MeshMultipeerSession` mints the `MCPeerID` in `init`; `updateDiscoveryInfo` restarts only the advertiser). Presence must not reach testers over MC; item 2 pass 2 / item 4 remove the path.

- **A transport-error door that was start-failure-only under MC becomes any-error under QUIC.** `handleTransportError → stop()` was reachable only from `didNotStart*` under MC; a QUIC session that `report()`s a per-dial miss or its own task cancellation through the same door stands the whole radio down. Every `report`/`onTransportError` call in a new session must be classified: start failure (stand down) vs. per-operation refusal (log and return) vs. cancellation (silent).
- **24 advertised presence tags were already 311 bytes — over DNS-SD's 255-byte TXT entry limit.** MC's behaviour on an oversize `discoveryInfo` value was never established; `NWTXTRecord` refuses or truncates. The TXT is now chunked `t`/`t1` (capacity 36) with a cell pinning `maxAdvertisedTags <= capacity`.
- **Owner follow-up, not fixed:** `NetworkMeshSession`'s listener/browser task bodies (`:~834`, `:~877`) have the same unguarded `catch { report(…) }` shape; the mesh's owner only sets `discoveryError` (a banner), so a real cancel may show a spurious banner — left alone because guarding it changes what the mesh records. **Decided and fixed 2026-09-20:** guard both bodies. The republish path (`updateDiscoveryInfo(_:)` — every mesh-mode change, merge and member-count change) never clears `discoveryError` and runs on a live search with the banner's own screen up, so a reported cancel is a "discovery failed" banner pinned until the user leaves the tab; the hold and stop paths clear it BEFORE the cancel lands, so their clear never wins and the banner is hidden there only by `isSearching == false`. The `.cancelled` state callback was already silent, so the task body now agrees with it. What the mesh records on a real cancel is nothing — which is `discoveryError`'s documented contract (a start-up failure, and a cancel is not one). Cell: `NetworkMeshSessionTests.theListenerAndBrowserTasksDoNotReportTheirOwnCancellation`, a source scan for the same reason the presence cell is one.

- **Two foreground agents cannot hand a build slot to each other through the orchestrator.** The item 3 drafter polled for the marker file for 100 minutes while the orchestrator was blocked waiting on both it and the lane runner; the marker could only be created after both returned. Either run the drafter in the BACKGROUND, or let the runner create the marker itself when it is done with the tree.
- **`-only-testing:FernletTests/<FileName>` matches nothing and reports nothing** — the run proceeds with the other suites and the file's suites silently contribute zero. Name the struct; count the suites in `Test run with N tests in M suites` against the list.
- **A sole-friend pair never surfaces in presence**: layer-3 self-exclusion drops an ad whose token set is a subset of our own, and two devices whose only friend is each other advertise identical sets. Accepted residual; seed a third friend on every presence lane run, and remember the diagnostic is in-memory only.
- **The launcher's item 3 premise was wrong twice** (verified by the pass-1 survey): the recipe share is one sealed frame with no chunks or offsets, and the recipe radio used the persistent device-name `MCPeerID`. Read the file before believing a launcher row's description of it.
- **A `MeshLinkKey` built from a Bonjour endpoint id IS the advertised name.** "Opaque" must be proven by a cell over the audit capture, not asserted in a comment.
- **A long single `Task.sleep` to a wall-clock deadline wakes late in proportion to its length on a loaded host** (+0.8 s at 300 s, +51 s at 767 s, both Simulators together). Await deadlines in bounded steps and re-read the clock on every wake.

- **A field that only TRANSITIONS write is born wrong whenever the level was already set.** `radioIsQuiet` mirrored the radio's pause, but only the gate's pause/resume verdicts wrote it, so a transfer minted while the radio was already paused carried `false` for its whole life — and the cell meant to catch it drove the session directly and asserted the birth value. Seed every mirrored field from the level at construction, and make the cell mint UNDER the level it claims to mirror.
- **`??` is a nil-coalesce, not an empty-coalesce.** A publisher that can emit `""` for a key whose receiver only falls back on `nil` renders the placeholder where the old path rendered the user's text. Either never emit the empty value (omit the key) or fall back on both — pass 1 did both.
- **`ML5` (`MemoryLifecycleBoundaryTests`, HP0) is a tree-wide grep wall the compiler and the new suite cannot see**: five inline `ProximityRecipeShareManager(store: SomeHost())` test hosts built clean and every recipe-share cell passed; only that suite named them. Every new proximity-manager test file runs `MemoryLifecycleBoundaryTests` before it is believed.
- **A needle that counts occurrences survives relocation.** `occurrences("session.pauseDiscovery()") == 1` was true with the call moved out of `applyDiscoveryGate(`; the needle now pairs the whole-file count with the count inside the function's brace-matched body.
- **`Scripts/spm-wall-check.sh` leaves NO `FernletTests.xctest` in DerivedData** (it rebuilds under the enforcement flag): a verify agent that runs after it cannot `test-without-building`; run the wall check LAST and expect a `build-for-testing` before the next test run.
- **`ItemNameModeration.sanitizedName` strips ZWJ** — a family-emoji name cell passes for a different reason than a byte bound; pass 2's TXT publisher must not assume ZWJ sequences survive the sanitizer. It KEEPS combining marks, which is how a single grapheme reaches 64+ bytes.
- **An unbuilt draft compiled first try bar one class of error** (`#expect` cannot hold a mutating call — `'$0' is immutable`); the ML5 hosts and the two FIXes were the real cost. Phase A's anchoring by surrounding text (not line numbers) held across one intervening commit.
- **A fake that does not model the real session's ORDERING hides a total outage.** The QUIC recipe session booked the pending-inbound entry before the owner's gate ran; the gate's `!hasConnectingPeers(besides:)` saw the dialer's own connection and refused EVERY inbound dial, while 25 cells over a fake with no pending inbound stayed green. A seam's fake must book-before-gate (or whatever the real one does) at the same instant; a lane row ("an inbound dial completes at all") is the only cell that cannot lie.
- **The launcher's item 4 premise was wrong**: "MC now stops at two files" (P0/P1) meant two files CONTAIN it, not that it is dead. The friend mesh ships on MC by default and QUIC has no stranger-admission path. Grep `shippingDefault` before believing any "retire X" row.
- **`Docs/PrivacyWipeCoverage.md`'s permit-style lists never scanned `Tests/`**: 32 test files name MC. A deletion's blast radius is the whole tree, not the scan roots.
- **A lane finding can be pre-existing and still a blocker**: P9-3-A (a configured lock parks the 1:1 radios forever) was found by the 9.3.2 harness, not caused by it; record the class (pre-existing / regression) on every lane finding.
- **True glare IS reachable on Simulators** with a harness that dials on sight (17 µs apart) — do not mark glare inconclusive without trying an auto-dial.
- **zsh does not word-split an unquoted `$ARGS`** — the second time this bit: 117 `-only-testing:` flags passed as one argument reported `TEST EXECUTE SUCCEEDED / EXIT=0 / Executed 0 tests`. Build argv as an array; always read `Test run with N tests in M suites`.
- **A drafter and a lane runner can share a tree** as long as the drafter is read-only and returns without waiting on a marker.
- **A floor written in a draft is stale the moment another item lands a cell in a gated suite**: every 469 anchor in the 9.6 drafts was wrong by the time they were applied (9.5's cell had moved it to 470). Measure the floor at the commit that moves it; never carry a number across commits.
- **A cell whose home suite is a wall suite moves the CI floor**: 9.5's rule-7 cell landed in `MeshContinuationTaskHostWallTests` (the draft named the sibling suite) and the mesh-batteries floor had to move with it, in the same commit.
- **The selector wall protected only `MeshP<n>*AcceptanceTests` by name.** Any other gated suite could be dropped from the workflow line with every wall green; the floor is the only guard for the rest. Price a name pin before believing "gated".
- **An audit line with NO context key cannot be scoped by a test** — the fix is production, however small, and it must extend the existing call (a `log(` count wall stands beside it).
- **"Retire the anchors" read literally deletes the reaper**: the attributes type the doomed conformer used is the same one the orphan reaper enumerates. Before deleting a type, list every reader, not every writer.
- **A retirement cell that pins what must be ABSENT is half a wall** — 9.4-NOW's cell pinned the four dead strings absent and three QUIC strings present but forgot the two the shipping mesh still uses; a deletion of a live string would have been green. Pin the live set as hard as the dead one.
- **Scoping two counts in a file that holds twenty is not a fix; it is a map of the other eighteen.** 9.7 closed the two `parkedReoffered` sites and 9.6 then gated the file — the verify found ~20 siblings with no key at all. Sweep the FILE for the token family, not the launcher's list.
- **A suite name that matches neither half of the selector's predicate is demanded by nothing** — `MeshP9CIHonestyTests` would have been a battery CI never asked for. Check a new suite's name against `isMeshBattery` before writing it.
- **A gate script that cannot see `Restarting after unexpected exit` will report an inflated green**: a restart re-runs suites and the total climbs past the floor. The check now lives in `run-gated-suites.sh` (proved at a `--check-log` seam only).
- **The verify agent could not write its findings file** (a harness block on that path) and returned them inline; the orchestrator transcribed them. Do not assume a scratch path is writable by every agent.
- **A ledger row can be wrong about a mechanism while right about the fact**: "`MeshNetworkManager.init` constructs `MeshMultipeerSession()`" — it resolves the factory; the ONE construction site is `MeshTransportSelection.swift`. A drafter grepping the ledger's claim found zero hits. Name the site, not the caller.
